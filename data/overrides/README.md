# ACatalog overrides

Place reviewed icon replacements in `data/overrides/icons/<slug>.webp`. Files must be WebP 512×512. Add the corresponding `sourceUrl` and `licenseNote` entry to `icons.json`; manual files take precedence over fetched and generated icons.

Application-field overrides belong in `apps.json` and are applied by stable application ID. Every override must include a human-readable reason.

Ambiguous Compose directories can be mapped explicitly in `compose-mappings.json` using `sourceRepo/directory` as the key and the stable application ID as the value.

`deployments.json` is generated by `npm run data:deployments`. It records official repository Compose files, exact commits, and minimal clones stored under `raw/deployments/`. Do not add generated or guessed Compose files: only configurations that parse successfully and declare at least one `services` entry are accepted.
